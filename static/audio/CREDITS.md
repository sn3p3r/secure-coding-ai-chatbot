# Audio credits

Every file in this folder, where it came from, and its licence. The
same list is shown to players in the CREDITS tab at the bottom of the
site (`templates/_faq.html`, data in `curriculum.MUSIC`); which level
plays what is in `courses/soundtrack.py`.

All five tracks are by Kevin MacLeod (incompetech.com), licensed under
Creative Commons: By Attribution 4.0 License,
http://creativecommons.org/licenses/by/4.0/. Files are unchanged; the
browser loops them where noted.

| File | Title | Used for |
|------|-------|----------|
| `music/ossuary-1-a-beginning.mp3` | "Ossuary 1 - A Beginning" | Beginnings and quieter fights; looped on every obelisk level |
| `music/vibing-over-venus.mp3` | "Vibing Over Venus" | Calm levels with nothing to fight |
| `music/blobby-samba.mp3` | "Blobby Samba" | Levels where you fight bugs and viruses |
| `music/cretaceous-dawn.mp3` | "Cretaceous Dawn" | Looped from the moment a boss appears |
| `music/rhinoceros.mp3` | "Rhinoceros" | The first time you enter each course's lab (one level per course) |
